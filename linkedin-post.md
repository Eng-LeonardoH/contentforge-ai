# ContentForge AI — Thumbnails virais em 1 clique

Acabei de lançar um gerador de thumbnails que une IA + design programado.

🎯 **O que faz:**
- Upload de imagem → 8 thumbnails automáticos
- IA sugere textos, cores, tipografia
- Estilos: Neon, Gradient, TikTok, YouTube, Minimal, etc.
- Tamanho otimizado para cada plataforma
- 100% client-side, sem backend

🛠 **Tech:**
- HTML5 Canvas API
- Tailwind CSS
- JavaScript puro (sem frameworks)
- Design responsivo

📸 **Resultado:** thumbnails prontos em segundos, com prompts copiáveis pra IA gerar variações.

👉 Deploy: **https://eng-leonardoh.github.io/contentforge-ai/**
