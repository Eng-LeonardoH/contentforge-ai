# 📸 ContentForge AI

Gerador de thumbnails virais com IA — só upload e pronto.

## Como usar
1. Abra **[https://eng-leonardoh.github.io/contentforge-ai/](https://eng-leonardoh.github.io/contentforge-ai/)** no navegador
2. Clique em **"Escolher Imagem"** ou **"Usar Demo"**
3. Digite o título do seu vídeo
4. Escolha um dos 8 estilos gerados
5. Clique em **Baixar** ou **Copiar Prompt**

## Deploy rápido
```bash
# Local
python3 -m http.server 8080
# Acesse http://localhost:8080

# GitHub Pages (já publicado!)
# https://eng-leonardoh.github.io/contentforge-ai/
```

## Features
- 8 estilos diferentes (Neon, Gradient, TikTok, YouTube, etc.)
- Geração client-side (Canvas) — rápido
- Tamanho YouTube (1280×720) — pronto
- Sem backend necessário
- Prompts prontos para IA
